# Benchmark results

Command (Release build):

```
cmake -B build-release -DCMAKE_BUILD_TYPE=Release
cmake --build build-release
/usr/bin/time -l ./build-release/tagstream_bench data/companies.tsv data/bench_input.txt
```

Dataset: 10,398 company names from the SEC company tickers list (patterns); 200,000 synthetic headlines generated by `scripts/make_bench_data.py` with seed 42, about half mentioning a company. The naive matcher is timed on the first 2,000 lines only, and throughput is compared in lines per second.

Machine: MacBook Pro, Apple silicon (arm64), macOS. Chip: [add output of `sysctl -n machdep.cpu.brand_string`]
Compiler: [add output of `clang++ --version | head -1`]

Memory is the "maximum resident set size" reported by `/usr/bin/time -l`, for the whole benchmark process (including the 200,000 input lines held in memory).
